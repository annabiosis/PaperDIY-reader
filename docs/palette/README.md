# Палитра панели: 16 градаций серого

Кадровый буфер E-Ink контроллера M5PaperDIY — **4 бита на пиксель**, то есть
ровно **16 уровней** (0 — чёрный, 15 — белый). Режим GC16 (`epd_quality`)
рисует все 16; режимы DU (`epd_fast` / `epd_fastest`) — только два уровня,
поэтому в них текст идёт без полутонов.

## Значения для макетов

Линейная шкала: `8 бит = уровень × 17` → шаг `0x11` (17/255). Именно эти
значения используйте в Figma / Photoshop / Krita.

| Уровень | Hex | RGB | «Чернота» | Значение для кода (16n+8) |
|--------:|-----|-----|----------:|--------------------------:|
| 0  | `#000000` | rgb(0, 0, 0)       | 100% | 8   |
| 1  | `#111111` | rgb(17, 17, 17)    |  93% | 24  |
| 2  | `#222222` | rgb(34, 34, 34)    |  87% | 40  |
| 3  | `#333333` | rgb(51, 51, 51)    |  80% | 56  |
| 4  | `#444444` | rgb(68, 68, 68)    |  73% | 72  |
| 5  | `#555555` | rgb(85, 85, 85)    |  67% | 88  |
| 6  | `#666666` | rgb(102, 102, 102) |  60% | 104 |
| 7  | `#777777` | rgb(119, 119, 119) |  53% | 120 |
| 8  | `#888888` | rgb(136, 136, 136) |  47% | 136 |
| 9  | `#999999` | rgb(153, 153, 153) |  40% | 152 |
| 10 | `#AAAAAA` | rgb(170, 170, 170) |  33% | 168 |
| 11 | `#BBBBBB` | rgb(187, 187, 187) |  27% | 184 |

Колонка «значение для кода» — то, что нужно отдать в `fillRect`/`pushImage`
(8-битный серый), чтобы в буфере оказался именно этот номер уровня:
`value = 16·n + 8` (середина окна уровня после шага дизеринга драйвера).

| Файл | Для чего |
|---|---|
| `gray16.gpl` | GIMP, Krita, Aseprite, Inkscape — «Load palette» |
| `gray16.act` | Photoshop, Affinity Photo (Swatches → Load) |

| `gray16-hex.txt` | список `level / hex / css / driver` для копипаста в токены |

Пересобрать: `python tools/make_palette.py`.

## Важно про физику

16 — это число **цифровых** уровней. Реальная отражающая способность
электронных чернил не линейна и зависит от температуры и вейвформы: соседние
уровни (например 7 и 8) на глаз могут почти сливаться, а разница 0↔15 —
максимальная. Для макетов удобно держать сетку из 5 «рабочих» уровней:
`#000000`, `#444444`, `#888888`, `#CCCCCC`, `#FFFFFF` — они гарантированно
различимы на панели.
